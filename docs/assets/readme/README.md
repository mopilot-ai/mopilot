# README product previews

These images are captures of MoPilot's public website demo at https://mopilot.ai,
taken on 2026-10-26. They illustrate the product with the demo's sample projects,
accounts, code, and results. They are not evidence of a real app verification run.

- `workspace.jpg`: the interactive demo after choosing **Agent in the browser**.
- `switch.jpg`, `sessions.jpg`, `prs.jpg`, `accounts.jpg`, `browser.jpg`, and
  `computer.jpg`: the corresponding feature illustrations on the same page.

To refresh them, use a 1440 × 1100 desktop viewport. Capture the interactive
demo's app frame for `workspace.jpg` and each feature's illustration area for
the remaining images. Keep the preview disclosure and descriptive alt text
in the root README. Capture the public demo only; do not include personal chats,
account details, or unrelated desktop windows.
