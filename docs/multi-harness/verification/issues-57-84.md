## Found while verifying

Two regressions on main. The first is fixed in this PR; the second was fixed on main (#152) while this PR was open.

1. The e2e spec `claude-sessions.spec.ts` (Fork chat from here on Claude, D-62 and D-68) failed on main with "Something went wrong in this chat: Cannot read properties of undefined (reading 'layer')". The Composer passes a chat's capabilities to `composeCommands` before main has answered; those read `absent` with no Why, and `b.why.layer` threw. `composeCommands` now ignores a binding without a Why (src/harness/commands.ts, test in tests/commands.test.ts). The spec passes with the fix.

2. src/styles/app.css was missing the closing brace of `.welcome code` (a merge of the welcome flow and the extensions page), so the file did not parse and tests/styles.test.ts failed (two tests).
