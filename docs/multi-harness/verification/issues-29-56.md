Counts, before this PR: fixed 22, partial 4 (D-35, D-38, D-49, D-55), not fixed 2 (D-42, D-43).
After this PR: D-38, D-42 and D-55 are fixed, D-43 is partial, D-35 and D-49 stay partial. Since then D-43 (#167) and D-49 (#170) are fixed; D-35 is fixed too (opt-in setting for the shell's cloud-provider variables).

- **D-35 (fixed).** Shell-exported cloud-provider switches are stripped by default and pass through to Claude Code only when the user turns on "Use cloud provider variables from my shell" in Settings > Claude Code.
- **D-43 (partial).** The signed-out banner still re-signs the account in use and has no "Use <other
  account>". Next step: make `SignedOutBanner` take the chat's account when it is shown inside a chat and
  add the switch button the Codex banner has (`CodexExpiredBanner`, `src/components/Accounts.tsx:471`).
- **D-49 (partial).** Grey out Goal in the "+" panel and `/goal` on an ephemeral chat (reason: "Temporary
  chats can't have goals") and restore the typed text when `goal/set` fails. Low severity; the "+" panel
  items have no disabled state yet, so it needs a small menu change.
- **Needs a real CLI or a person:** D-32 end-to-end (a real Codex reading the key through `auth.command`),
  D-41 sign-in from a signed-out Claude CLI, D-37 and D-43 against two real logins (FOLLOWUPS WP3).
- **No guarding test:** D-36, D-53, D-56, and Remove key in D-33. Each is a small copy or wiring check.
